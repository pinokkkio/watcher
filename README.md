# moex-watcher

Мониторинг Московской биржи: уведомления о **сильных** и **аномальных** движениях акций, облигаций
и фьючерсов, плюс рейтинг **самых волатильных** инструментов.

Данные берутся из публичного API биржи [MOEX ISS](https://iss.moex.com/iss/reference/). Без подписки
котировки идут с задержкой около 15 минут. С подпиской на данные можно указать логин MOEX Passport
в `[iss]`, тогда задержки не будет.

## Что отслеживается

| Тип | Сигнал | Смысл |
|---|---|---|
| Сильное движение | `STRONG_DAY` | изменение к закрытию прошлого дня пересекло уровень (акции 3/5/7/10/15%, облигации 1/2/3/5/10%, фьючерсы 2/4/6/10%). Каждый уровень срабатывает один раз в день в каждую сторону. |
| Сильное движение | `FAST_MOVE` | изменение за короткое окно (по умолчанию 5 минут) ≥ 1.5% / 0.7% / 1.0% |
| Аномалия | `ANOMALY_DAY` | дневное изменение ≥ 3σ *собственной* дневной волатильности бумаги (σ считается по 60 торговым дням). Повторно срабатывает при росте ещё на 1σ. |
| Аномалия | `ANOMALY_FAST` | изменение за окно ≥ 4σ, где σ — дневная волатильность, приведённая к длине окна (σ·√(окно/сессия)) |
| Аномалия | `VOLUME_SPIKE` | оборот в 3+ раза выше нормы для этого времени дня. Повторно срабатывает при удвоении. |

Почему нужны оба типа: +3% по ОФЗ или голубой фишке с σ≈0.8% — событие (аномалия), а для
волатильной бумаги второго эшелона это обычный день. Абсолютные пороги ловят просто большие
движения, z-score ловит необычные именно для этой бумаги.

Неликвидные инструменты отсекаются по обороту за сегодня и среднему дневному обороту
(`min_value_today`, `min_avg_value`). Если по инструменту несколько сигналов за один опрос,
они приходят одним уведомлением.

## Установка

```bash
pip install -e .
```

## Использование

Непрерывный мониторинг: в консоль, в `data/alerts.jsonl` и в Telegram, если он настроен.

```bash
moex-watcher -c config.toml watch
```

Только акции и фьючерсы:

```bash
moex-watcher -m shares,futures watch
```

Самые волатильные сегодня по дневному диапазону high-low:

```bash
moex-watcher -m shares volatile --top 20
```

Самые необычные сегодня, по изменению в сигмах:

```bash
moex-watcher -m shares,futures volatile --mode z
```

Историческая волатильность (годовая, %) за 20 торговых дней:

```bash
moex-watcher -m shares,corp_bonds volatile --mode hist --days 20
```

Проверка канала уведомлений:

```bash
moex-watcher -c config.toml watch --test-notify
```

Рынки: `shares` (TQBR), `etf` (TQTF), `ofz` (TQOB), `corp_bonds` (TQCB), `futures` (FORTS, RFUD).
Свои режимы торгов добавляются в конфиге через `[markets.<имя>]`.

В режиме `watch` каждые `digest_interval_min` минут (по умолчанию 60) приходит сводка
«самые волатильные сегодня» по каждому рынку.

## Настройка

```bash
cp config.example.toml config.toml
```

Все пороги задаются отдельно для `shares`, `bonds` и `futures`, см. комментарии в
`config.example.toml`. Для Telegram создайте бота через @BotFather и укажите `token` и `chat_id`.

Дневная история кэшируется в `data/history.sqlite`. Первый запуск загружает около 60 торговых
дней по каждому режиму, это несколько сотен запросов к ISS. Дальше подгружается только новый день.

## Устройство

```
moex_watcher/
  iss.py         клиент ISS: снимки рынка (securities+marketdata), дневная история с пагинацией
  history.py     SQLite-кэш дневных итогов; σ, средний оборот, ATR по инструменту
  detectors.py   детекторы сильных/аномальных движений, состояние уровней и антиспам
  volatility.py  рейтинги волатильности (исторический и внутридневной)
  notifiers.py   консоль, Telegram, webhook, JSONL
  engine.py      цикл опроса
  cli.py         команды watch / volatile
```

Опорная цена для дневного изменения: у акций и облигаций — официальная цена закрытия прошлого дня
(`PREVLEGALCLOSEPRICE`, запасные варианты `PREVPRICE` и `PREVWAPRICE`), у фьючерсов — расчётная
цена прошлого клиринга (`PREVSETTLEPRICE`). Цены облигаций считаются в % от номинала.
